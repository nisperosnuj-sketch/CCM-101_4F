# Mission 3 Reflection

## 1. Cloud Platform Impression
Among the three cloud providers evaluated, Google Cloud Platform (GCP) impressed me the most due to its clean architecture, developer-friendly interface, and industry leadership in data analytics and containerization. GCP’s native integration of Google Kubernetes Engine (GKE) and BigQuery demonstrates how cloud platforms can simplify complex distributed systems and big data workloads without unnecessary configuration overhead.

## 2. Platform Similarities
Despite differences in branding and console interfaces, AWS, Azure, and GCP share fundamental cloud architecture principles. All three providers offer core Infrastructure as a Service (IaaS) categories: Virtualized Compute, Object and Block Storage, Virtual Private Networking, and Identity and Access Management (IAM). Additionally, each platform utilizes a regional global infrastructure model consisting of isolated Availability Zones linked via high-speed fiber networks.

## 3. Impact of Business Requirements
Business requirements dictate cloud provider selection far more than technical feature counts. Factors such as existing software licenses, internal staff expertise, regulatory compliance mandates, budget constraints, and specialized hardware requirements (e.g., GPUs/TPUs) drive architectural choices. As demonstrated in this mission, an organization relying on Microsoft Active Directory naturally fits Azure, whereas a machine learning research group derives greater value from GCP.

## 4. Learnings as a Cloud Solutions Consultant
Acting as a Cloud Solutions Consultant emphasized that cloud engineering extends beyond technical configuration to strategic business alignment. A Cloud Architect must evaluate cost efficiency, scalability, vendor lock-in risk, and operational overhead rather than simply choosing the market leader. Objective decision-making based on client requirements is essential for successful cloud migration strategies.

It demonstrates both technical competency in cloud concepts and clear technical communication skills to prospective employers.
