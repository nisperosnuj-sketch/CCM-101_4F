## Comparative Analysis Questions

### 1. Which cloud provider offers the broadest range of services?
Amazon Web Services (AWS) offers the broadest range of services, featuring over 200 fully realized cloud services. Due to its first-mover status, AWS provides deeper functionality within individual services compared to its competitors.

### 2. Which provider best integrates with Microsoft technologies?
Microsoft Azure provides the best integration with Microsoft technologies. Organizations leveraging existing Active Directory, Windows Server, SQL Server, and Microsoft 365 licensing benefit from native compatibility and cost savings through the Azure Hybrid Benefit.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?
Google Cloud Platform (GCP) is the strongest in Artificial Intelligence and Kubernetes. Google originally developed Kubernetes and offers the industry's most mature managed container environment (GKE), alongside native AI infrastructure powered by Vertex AI and custom Tensor Processing Units (TPUs).

### 4. Which cloud platform would you personally choose and why?
I would personally choose **AWS** because of its unmatched documentation, industry adoption, and extensive service catalogue. Learning AWS provides high versatility across various business requirements, making it an ideal platform for general-purpose cloud engineering.
