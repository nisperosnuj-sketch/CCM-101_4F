## 1. Which cloud infrastructure component do you think is the most important? Why?

I think compute resources are one of the most important cloud infrastructure components because they 
provide the processing power needed to run applications and services. Without compute resources, the other infrastructure 
components would not be able to support running workloads effectively.

## 2. How does Linux support cloud computing?

Linux supports cloud computing by managing important resources such as CPU, memory, storage, 
and networking. During this laboratory, I used Linux commands in the KillerCoda environment to investigate the 
operating system, CPU, memory, storage, hostname, and IP addresses of a cloud-based server.

## 3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it provides a clear record of the infrastructure, configuration,
and decisions made before deployment. It can help engineers understand the environment, identify possible problems, 
and plan the cloud infrastructure more effectively.
